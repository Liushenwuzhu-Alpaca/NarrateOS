# 作者契约、物理节拍与多语域声纹细则

在 `narrate-boot` 第二幕对齐三锚与第三幕组装编译包时使用本细则。`lock_charter_and_boot` 的参数结构与配额以当前工具 Schema 为唯一真源；本文件约束结构校验无法替你判断的创作语义。

## 1. 契约要能裁决冲突

- **核心承诺可判案**：`commitments` 描述读者持续获得的体验、世界底层边界与回滚授权范围，而非抽象形容词。后续剧情发生张力时，应能据此裁决保留哪条事实、修正哪条路径。
- **`T0` 原话守恒**：`t0_anchor` 完整保留作者锁定的开场时刻、地点、在场人物、持有物与初始困境；角色的非主线私欲与信息盲区用于驱动当下行动，而非提前写死人物结局。
- **局部闭环与远期留白并存**：`OPEN_HORIZON` 允许跨卷终局留白，`Local Closure` 要求首卷摆上台面的核心异常具备第一层因果解答（如先拆穿人为机关，再露出底层异常），二者互不抵消。
- **卷级蓝图最小标记**：`l1_volumes_markdown` 支持单卷完结（`>= 1` 卷）或多卷连载，正文至少包含 1 个 `vol_01` 或 `第1卷` 标题标记。
- **排雷与底牌物理隔离**：`excluded_cliches` 与幕后底牌只进入全知契约（对写手物理屏蔽）；写手可见资产只陈述可演绎的正向具体目标。

## 2. 节拍以不可逆物理相变完成（严防原地水字数）

`opening_sequence_beats` 按因果顺序推进，不绑定固定章号或故事天数（首章受 `first_chapter_max_beats` 默认 `1` 拍约束）。
- **过拍标志 (`completion_sign`) 必须是一眼可核验的物理位移、证物交接或公开表态事件**：例如「拿到四楼备用钥匙并锁门离开旧校舍」「当面核对出账册三百两缺口并迫使掌柜交出当票」。切勿写成模糊的心理变化或悬空意向（如笼统的心境波动、关系升温或口头约定次日再查）——以物理动作完成作为过拍准绳，是防止多章卡在同一时间点反复水字数的核心抓手。
- **二值核销链路**：`Planner` 以 `target_beat_label` 提名当前拍，`Fact Checker` 对照定稿核实 `completion_sign` 客观达成后在 `confirmed_completed_beats` 确认，管线自动将该拍更新为 `COMPLETED`。仅提名、触及线索或角色口头猜测均不算过拍。

## 3. 阶段禁区与公开舞台冰山分流

- `stage_ceiling`（写入 `world/arc_director_plan.md`）划定本阶段不可提前写破的谜底或战力跃迁，仅供 `Planner`、`Fact Checker` 与 `Dreamer` 使用。
- `current_arc_envelope` 只写角色眼前可见的公开舞台与正向行动冲突；角色在剧情中的保密动作或道具上的短引号字样属于正常戏剧内容，但绝不能包含面向写手的元禁令。
- `static_base_and_voice` 仅写公开常驻法则、空间连通拓扑与抽象句法纪律（严控 `<= 1,500` 字且零否定词）；行业考据规程与背景设定拆分放入 `lore_entries`；尚未揭露的隐藏法则放入 `unrevealed_pivots` 或实体第 2 区 `OMNISCIENT_SECRET` 槽位。

## 4. 多语域声纹配方（`author_sample` vs `boot_seed`）

- **有样章优先提纯**：作者提供样章时，优先提取或去名化为**不含初始角色专名/别名且通过 `StaticProseGate`** 的纯净动作/对话原句作为 `author_sample`（永久保留，不被滚动置换；`boot-validation` 对 `author_sample` 同样执行脱专名与静态门禁校验）。
- **无样章构造 `3-4` 条互补 `boot_seed`（或留空池）**：按第二幕作者选定的主导腔调，构造 `3-4` 条分属不同语域 `tag`（如硬动作反馈、短促口语交锋、冷幽默物象白描）、每条 `15-45` 字的启动种子；若作者偏好首章完全无预设种子，也可传空数组 `[]`。
- **防拒杀铁律**：每条声纹必须**零角色名/别名、零案情谜底、零抽象心理套话**（通过 `StaticProseGate`）。只要传入非空 `voice_samples`，就切勿只传 1 条样本——一旦单条样本被门禁过滤导致有效样本归零，`lock_charter_and_boot` 会直接整包报错拒绝建库；保持 `3-4` 条多语域样本既保建库稳健，又支撑 `Planner` 按 `preferred_voice_tag` 轮换抽样并在前 3 章定稿时自动用正文好句滚动置换。
