# NarrateOS 开书构思与重大改纲指南

本技能服务于主对话总导演与作者的全知协作：**自由构思深聊、严谨编译门禁、建完停机检阅、首章实测校准**。

## 核心铁律

1. **禁止直接写库与跳过停机**：严禁在主对话使用裸文件工具直接写 `books/<slug>/`，建库必须通过 `lock_charter_and_boot` 完成；建库通过门禁后**立即原地停机**，严禁自动生成第 1 章。
2. **先取证后提问**：先读透作者种子或设定文本，用 `web_search` / `web_fetch` 考据可查明的行业、时代、地理或制度细节，再针对影响主干的真实创作取舍向作者提问。
3. **只读参考按需加载**：详细模板与核验清单按需查阅同目录下的 `references/charter-and-beats.md`、`references/t0-causality-checklist.md`、`references/replan-protocol.md`。

## 流程 A：新书开书对齐与建库（4 步收口）

### Step 1：取证与排雷
- 通读作者创意、大纲或外部设定包（原著材料仅作为参考来源，保留 `>=98%` 专名与既成事实守恒）。
- 联网提炼 **5-8 条真实运作肌理**（行业规程、账期制度、气候物理约束等），让冲突长在具体机制上。
- 显式列出当前题材最廉价的默认套路并排除（写入 `author_charter.md` 留档，对写手物理屏蔽）。

### Step 2：按依赖对齐（3 必选底座 + 2 按需模块）
通过 `ask_user_question` 按依赖顺序分轮对齐，每题附带备选代价与推荐方案，向作者全知摊开影响核心解法的底牌与阶段取舍：

1. **必选底座一：契约、边界与 `T0` 原话现场**
   - 核心阅读回馈、世界物理/超自然边界、POV 切镜体制、叙述人称与主观度基线（如第三人称客观镜头或强主观第一人称）、卷/副本尺度（支持 `>=1` 卷单卷完结）。
   - **逐字锁定 `T0` 开局现场**（`story_day = 0` 的精确时刻、地点、在场人物、持有物与初始态势，保留作者原话锚点）。
2. **必选底座二：自主人物与外部压强**
   - 为每位核心角色定义主线目标之外的**非主线私欲/软肋**与**有限信息下的合理误判**。
   - 明确驱动局势演进的外部惯性压强（敌对/同盟角色行动，或自然气候、制度账期、生存规则）。
3. **必选底座三：首程弧光与无章号开篇序列节拍（3-5 拍）**
   - 明确首卷收束新常态与 `Stage Ceiling`（本阶段严禁提前写破的底牌/禁区）。
   - 将开局至第一幕转折拆解为 **3-5 个不绑死章号、按序消耗的节拍台阶（`Opening Sequence Beats`）**；每拍规定：体验/手艺落点、限量放出的 1-2 个线索、达成过拍的可见标志。
4. **按需模块 A：信息差与局部闭环（悬疑/暗线/错位喜剧激活；明牌日常允许 0 黑幕）**
   - 跨卷终局允许远期留白（`OPEN_HORIZON`），但当前卷摆上台面的核心异常必须具备第一层因果闭环（`Local Closure`）。
5. **按需模块 B：多卷续航 / 同人魔改差值（`Canon Delta`）**
   - 多卷连载明确跨卷新压强来源；大体量同人设定不做全量硬压，静态背景分片入 `lore_library/`，开书仅对齐 `T0` 人际切面与魔改清单。

### Step 3：常识因果自检与调用 `lock_charter_and_boot`
收口前执行 4 项因果自检（详见 `references/t0-causality-checklist.md`）：
- 幕后方动机经济性（为何不选更省事方案）
- 关键线索物理可达路径（主角如何合法接触线索）
- 主角不可替代手艺（为何非他不可）
- 声纹池洁净原则（作者提供样章才洗净入池；**无样章则声纹池保持 0 条空置，严禁伪造占位示例句**）

向作者呈报精简契约总览，待作者**显式确认**后，调用 `lock_charter_and_boot` 提交锁定快照，触发三把手术刀编译（视角刀/时序刀/冰山声纹刀）、初始化门禁验收与初始 Git 提交（`last_committed_ch = 0`）。

### Step 4：建库停机与首章校准交接
`lock_charter_and_boot` 完成后**立刻停机收口**，告知作者：
1. 作品仓库已建好并处于待命态，请先在右侧 Operator Studio 检阅生成资产；
2. 检阅无误后由作者**手动点击启动第 1 章**（或使用 `/narrate-step`），首章将仅消费开篇序列第 1 拍并以 0 声纹（或已清洗样章声纹）起笔；
3. 首章归档后系统自动停机，待作者完成体验核对（微调润色直接在线改稿走 `Sync`，设定偏差按因修订），确认通过时自动触发 **`Voice Harvest`** 从 `ch_0001.md` 采集 3-5 条脱敏纯表达标本入池，再由作者手动放行日常推进或 YOLO 连跑。

## 流程 B：卷中重大改纲与契约修订

当作者在连载中途提出推翻核心设定、调整卷末收束、变更 `Stage Ceiling` 或处理无法自动恢复的 `SAFE_HALT` 时，加载并严格遵循 `references/replan-protocol.md` 执行增量修订，**严禁覆写已定稿 `manuscripts/` 事实真源或篡改 `Innate Locks`**。
