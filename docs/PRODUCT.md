## 范围与规范关系

## 目标用户

主要用户是熟悉 AI 工具的个人小说作者：能够配置模型，愿意在开书阶段对齐核心意图，并在日常连载中监督生成、抽查成稿或在关键节点介入裁决。

用户承担全知导演与作品负责人的角色。自动化承担资料取证、多轮检索、排纲、净室执笔、事实核查与跨章资产维护；作者掌握核心承诺与审美校准，可灵活切换逐章共驾与连续生成（YOLO）。

## 产品目的与成功标准

NarrateOS 是运行于 DeepSeek Harness（`@deepseek-ai/dsh`）生态之上的通用长篇小说多智能体写作引擎，将开书构思、建库验收、开篇校准、章节生产与周期维护组织为可干预、可观测、可追溯的创作闭环。

成功意味着：

- 作者可在「NarrateOS 创作模式」下从创作种子或外部设定完成构思对齐、锁定《作者契约》并建立标准作品库，建库完成后由作者自主掌控开写时机。
- 作者可随时区分空闲待命、正在推进、安全点等待与冲突挂起状态，并能**直接点进正在运行或已完成的任意后台工种节点，实时查看其思考过程与工具调用轨迹**。
- 人工手稿修改、底部微调信号与聊天栏操控指令均落实到真实的作品纯文本资产与 Git 历史，而非仅改变界面显示。
- 自动修复与回滚遵循显式授权边界，作品资产不会因页面刷新、连续运行或异常中断失去一致性与可追溯性。

以上是产品判断标准，不构成未实测的质量、速度或商业收益承诺。

## 产品机制与双入口定位

- **专属创作模式与双入口协同**：以 `@deepseek-ai/dsh` 的「NarrateOS 创作模式」提供纯净创作环境（自动关闭编码向冗余工具）。开书构思与重大改纲复用主对话会话配合构思 Skill；日常推进与审阅采用三栏 Operator Studio 导演工作台（同时支持在聊天栏通过零模型开销的 `/narrate-*` 斜杠命令快捷操控）。
- **按钮拉动管线，指令框零 Loop 投递**：Studio 顶部按钮触发后台管线按序拉起各工种；中栏底部的输入框不运行对话 Agent Loop，专门用于向 `.ops/signals.jsonl` 投递传给后续工种的安全点微调指令（待消费信号支持撤回）。
- **手稿真源与双粒度事务**：每部作品存放于独立 `books/<slug>/` Git 仓库；定稿手稿是唯一已发生事实真源，实体档案与分级目录为派生物化视图，遵循预写相位锁（WAL）与双粒度原子提交。
- **多轮受控探查与单轮净室执笔分离**：检索、规划、核查、抽取与睡眠整理通过受控工具查证原稿并经终态门禁交棒；写手保持零工具单轮净室，物理隔离未揭底牌、`WARPED` 废案、作者契约与阶段禁区。
- **配置与代码本体解耦**：各工种的模型池、工具开关、调用配额与提示词外置为声明式配置（支持单书覆盖），不在内核硬编码先验题材枚举或固定魔数。

## 主要工作流

1. 切换至「NarrateOS 创作模式」，在主对话中通过 `/narrate-boot` Skill 讨论构思并锁定《作者契约》，后台完成建库与门禁验收后原地停机。
2. 切入 Operator Studio 检阅建库资产，点击「推进一章」（或执行 `/narrate-step`）生成正式第一章并停机完成开篇校准与原生声纹采集。
3. 逐章推进或启动 YOLO 连续生成；运行中可点击任意阶段节点在右侧分栏实时检视工种 `Conversation / Trajectory` 日志，需要停止时在安全点平稳收束。
4. 阅读正文、细纲与修改 Diff，通过底部信号栏（或 `/narrate-signal`）投递微调指令影响后续章节。
5. 直接编辑保存章节并执行 `Sync` 刷新派生状态，或触发多轮 `Dreaming` 整理卷纲、伏笔与实体履历；遇到 `SAFE_HALT` 时依据冲突行号与波及章数裁决后续动作。

## 能力与硬约束

- **作品资产物理隔离**：通用引擎仓库与具体作品物理隔离；每部作品使用独立的 `books/<slug>/` Git 子仓库，只读样本 [`manuscript/vol-01/ch-01.md`](../manuscript/vol-01/ch-01.md) 保持原样不改不续。
- **手稿优先与历史保护**：人工修改最新章自动增量同步；修改历史旧章仅执行下游只读冲突扫描并报告波及位置，严禁后台静默篡改下游手稿。
- **建库与校准显式放行**：建库完成与正式首章生成后均默认停机交作者把关，不未经授权静默连跑。
- **受控工具围栏**：主对话禁止用原生写工具裸改正式作品目录；后台工种仅能通过限目录、限配额且保护 `Innate Locks` 的领域工具与 `StagingSession` 访问作品资产。
- **真实证据原则**：不虚构作者案例、用户规模、商业指标或未经实测的质量提升比例。

## 产品原则

1. **作者掌舵，自动化执行**：用少量关键对齐锁定核心承诺，将日常检索、排纲、核查与台账维护交给受控工种自动闭环。
2. **真实资产优先于界面表象**：保存、撤回、同步与节点状态展示严格对应底层纯文本文件、Git 提交与宿主 Session 事实。
3. **长期因果韧性优先于单次炫技**：围绕契约守恒、局部闭环、成对回表、净室防污染与事务恢复组织创作。
4. **全程白盒可观测**：每个工种查了什么资料、改了哪行台账、为何被打回重修，均可通过原生会话轨迹直接点入核查。
5. **通用机制与声明式配置分离**：引擎固化确定性物理护栏，文学偏好与工种参数留在声明式配置与作品资产中演进。
