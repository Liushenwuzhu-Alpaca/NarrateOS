## 1. 信息架构纠偏：「单章手稿」与「全书设定集」彻底分离

| 维度 | 界面入口与名称 | 本质与数据真源 |
| :--- | :--- | :--- |
| **单章手稿**（本章维度） | 书稿上方分段胶囊：**`本章正文 ｜ 本章细纲 ｜ 改动对比`** | 仅对应当前选中的那一章。**本章正文是全书唯一事实真源**，支持随时直接改稿保存；`本章细纲` 自动将 `PlannerOutline` JSON 解析为中文节拍阅读页；`改动对比` 将 Git Diff 渲染为红绿删改对照块。 |
| **全书设定集**（跨章维度，替代原「物化视图」黑话） | 左栏底部（窄屏收纳进顶栏目录菜单）：**`人物与物品档案` · `未解伏笔清单` · `剧情预案与废案`** | 后台每写完一章从正文自动汇总出的跨章记账本：`人物与物品档案` 按实体 Markdown 四区拆解固有特征、当前状态与未揭底牌（标明写手不可见）；`剧情预案与废案` 优先展示 `[WARPED]` 已推翻隔离旧预案，下方附 `[PENDING]` 待推进后续预案。点击后通过原生 `View Transitions` 在主画布切换为独立设定集纸面，右上角配醒目的 `← 返回第 X 章正文`。 |

## 2. 全界面「去工程黑话 -> 作者直白中文」标准词表

底层协议字段保持不变，界面文案统一使用自然中文：

| 原先的工程黑话 / 代号 | 精修后的直白表达（保留自然的 `YOLO` 与英文模型名） |
| :--- | :--- |
| `▶ 推进 1 章 \| YOLO ▾` | **`▶ 写下一章 ｜ YOLO ▾`**（子项：`YOLO 持续连写` / `YOLO 连写 5 章`） |
| `安全点暂停 (force: false)` / `force: true` | 下拉二级项 **`写完本章暂停`** / 主操作 **`安全中止`**（取消在途调用并等待锁释放） |
| `↻ Sync (1)` | **`同步修改 (1)`** |
| `SAFE_HALT` / `sync_conflicts` | **`已暂停 · 发现设定冲突`**（按真实物理状态分流按钮组，见 §6） |
| `物化视图` / `实体卡` / `WARPED` | **`全书设定集`** / **`人物与物品档案`** / **`剧情预案与废案（含已推翻旧预案）`** |
| `DIRECTOR_NOTE` / `SPOTLIGHT_TRIGGER` / `FLASHBACK` / `RETCON` | **`剧情微调`** / **`切换视角（附人物选择）`** / **`插入回忆（回到第 N 天）`** / **`圆谎修补`** |
| `Librarian -> Planner -> Writer -> Fact Check -> Extractor -> Dreaming` | 保留干练英文 Agent 名 **`1. Librarian -> 2. Planner -> 3. Writer -> 4. Checker -> 5. Extractor -> 6. Dreamer`** |
| 右栏 `会话 \| 检查器 \| 模型路由` | **`思考过程 ｜ 运行状态 ｜ 模型分配`** |
| 检查器 `WAL / Kontoyiannis H_K / MATTR-500 / writerAssembly` | 默认展示直白三段：**`本章给写手装入的资料`** + **`文风体检`** + **`自动整理进度`**；底部附可折叠 **`底层校验与提交明细`** 收纳真实事务锁、双粒度 Git SHA、切镜队列与 `Checker` 验真筛除统计。 |

## 3. 升级版 `3x2` Agent 工序与模型灯阵（`Bolder` + `Animate` 强化）

- **收起态**：`10px` 状态指示灯（配非纯色光晕环与明确中文状态文案）+ 展开切换（`Agent 工序与模型 ▾`）。
- **展开态（`672px` 版心同宽对齐）**：平铺 `3x2` 紧凑卡片矩阵，每格清晰展示：**状态灯 + 英文工种名 + 中文执行状态 + 当前实时活动微文案（连写运行中动态呼吸流转）+ 实际生效的完整英文模型名**。
- **执行与归档分离**：工序徽标只展示当前运行；完成、切书或重跑时重置。历史尝试仍可通过工序卡打开，不会把待机节点误标为已完成。
- **运行中恢复会话**：重新打开工作台时，按 `GET /api/narrate/status` 的 `runtime.stageChapter` 和 `runtime.stageSessionId` 恢复本次工序，不把 WAL 的 `activeChapter` 当成工序章号。未定稿章的工序卡默认打开本次会话，即使书稿区仍在阅读上一章；同章同工序的历史尝试仍可切换，但不改变实时徽标。导演便签引发的状态刷新不会打断同一会话的恢复；切换工作区或收到更新的工序事件时，丢弃迟到的旧运行记录。
- **共享元素空间飞入**：点击任意工种卡片，通过浏览器原生 `document.startViewTransition` 将该卡片的状态灯与工种铭牌平滑飞入右栏「`思考过程`」顶栏，右侧主体完整保留 DSH 宿主原生会话流与 `stage:event` SSE 实时轨迹（含同节点多次尝试切换胶囊）。

## 4. 下章走向建议与底部一体式便签舱

- **纵向整句候选（零截断）**：可收折纵向 3 行卡片（与 `672px` 书稿严格同宽）；点击整行文字填入下方导演便签框供微调，点击右侧 `直接写 →` 立即以该目标调用单章生成。
- **一体式无框便签舱**：去除原生灰底 `<select>`；选择 `切换视角` 时同行展开活跃人物选择胶囊（自动绑定 `entity_id`），选择 `插入回忆` 时同行展开 `回到第 N 天` 数字框；投递便签后平滑滑入上方待生效便签轨。

## 5. 右栏「模型分配」：两层可编辑路由（对齐 [RoleRoutingEditor.tsx](../../packages/dsh-client-ui-studio/src/client/RoleRoutingEditor.tsx)）

1. **第一层 · 全局强弱基础模型底座（支持直接编辑保存）**：
   - 三类默认基础池（`强模型池` / `快模型池` / `独立挑错池`）均支持从候选列表选择或直接输入 `provider:model`，与第二层一并提交 `PUT /api/narrate/model-routing`。
2. **第二层 · 按 Agent 单独指定（手风琴按需展开）**：
   - 收起态单行展示工种名与当前生效模型（覆盖项以 `cobalt-ink` 高亮）；展开态提供 `强弱档位 (tier)`、`思考深度 (reasoning_effort)` 与 `指定具体模型 (model)`，修改后与中栏 `3x2` 工序矩阵实时联动。

## 6. 后端物理真源契约边界（`Q1` ~ `Q6` 对齐）

1. **双模式冲突裁决卡（绝不渲染无效按钮）**：
   - **已落盘跨章穿帮（`sync_conflicts.json` / `quarantine_report.json`）**：展示 `自动修补冲突`（调 `POST /api/narrate/heal`）+ `我自己动手改稿` + `写条便签解释原因`。
   - **写新章途中未落盘拦截（`safe_halt.json`）**：新章尚未写入 `manuscripts/`，卡片如实比对设定依据与草稿冲突原句，按钮分流为 `带上微调便签重写本章` + `先写便签调整走向`。
   - **执行中止或模型异常**：顶栏实时展示作品锁与当前工序；排空后提供 `原地重试`，正文尚未落盘时另可选择 `从头重跑当前章`。正文已落盘的断点交由 WAL 补齐账本。
2. **真实清样校勘触点（零捏造偏移）**：
   - 保留三大确定性清样签名：`02 | 标题` 68px 超细序号刊头、段落悬停 `P01` 页边标号、已定稿无手改章末 `-4deg` 宣纸印泥质感「`定稿`」朱印 + 真实 `commitSha`（有未同步手改时切换为「`待同步修改`」）。
   - 本章发生过 `LOCAL_PATCH` 自动润色时，在刊头下方展示 `本章已自动润色 N 处套话 · 查看思考过程` 校勘签（直达 `Patch` 会话），不在正文内猜测字符偏移画假虚线；新书 0 章时展示温润扉页引导。
3. **DSH 宿主容器断点与跨书草稿自动暂存**：
   - 响应式严格基于 `.ns-studio-shell` `ResizeObserver` 容器实测宽度：`>= 1200px` 三栏常驻；`< 1200px` 收起左栏至顶栏浮层；`< 820px` 右栏转浮层抽屉。
   - 废弃阻断式切书弹窗，按 `bookRoot + chapterNumber` 自动暂存未保存手改草稿并在切回原章时温和恢复；顶栏 `⋯` 菜单提供轻量内联弹窗承载换卷/完结封笔、多线并行分叉/合流与手动声纹提取，保留开书弹窗并附主对话构思引导。
   - 编辑器从 `GET /api/narrate/chapter?ch=N` 保存 `bookRoot`、`chapterNumber`、`sha256`；进入编辑后不随后台刷新更换基线。暂存稿的版本不匹配时保留可复制的原草稿，不自动将全文套用到新版。`PUT /api/narrate/chapter` 必须提交原作品、章号、`baseSha256` 和新 `content`。身份缺失返回 400，作品或原稿已变返回 409，均不备份、写稿或同步；成功返回新正文的 `sha256`。

## 7. Overdrive 满血清样剧场动效与渐进增强纪律

1. **原生 View Transitions 共享元素流转**：章节切换、正文/设定集翻转及 `3x2` 工序卡片至右栏思考流顶栏的状态灯共享变形，不支持浏览器自动无感回退。
2. **纯 CSS `animation-timeline: scroll()` 朱砂阅读丝带**：书稿纸面顶边内嵌 `2px` 极细朱砂进度条，零主线程开销跟随滚动铺展。
3. **内联 SVG `feTurbulence` 宣纸印泥「定稿」章**：真实纤维微斑驳边缘配合新章完成瞬间的 `360ms cubic-bezier(0.16, 1, 0.3, 1)` 落印阻尼动效。
4. **`Web Animations API` 新章段落墨迹显影**：新生成或润色刷新时逐段渐进遮罩显影，切章/连写立即 `cancel()` 清理，完整支持 `@media (prefers-reduced-motion: reduce)` 无位移降级。
