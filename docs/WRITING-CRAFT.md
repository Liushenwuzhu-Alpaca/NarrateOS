# 微观文风工艺与静态门禁词典 (WRITING-CRAFT)

> **定位**：提炼自 14 份成熟写作预设与长篇退化研究的可执行微观叙事规则集，服务于 `Prose Writer` 提示词构建、`Static Prose Gate` 可开关代码规则集与 `craft_plugins` 可选文风插件。
> **关联文档**：整体业务工作流见 [`ARCHITECTURE.md`](ARCHITECTURE.md)；裁决基线见 [`../ROADMAP.md`](../ROADMAP.md)。

## 1. 跨流派收敛的六大基础叙事铁律

跨越严肃白描、轻快吐槽与硬核沙箱等不同流派，以下 6 条是抑制文本滑向“AI 塑料感”的最小必要骨架：

1. **有限认知边界（信息三问防全知）**：角色只知亲眼所见、亲耳所闻或合理渠道获知之事。动笔与审校均按“信息三问”核查：角色当时在哪？消息传递渠道是什么？物理耗时够不够？视角角色之外的其他在场人物不直写心理活动，情绪一律通过动作、停顿与台词外显。
2. **底层性格锚定**：重大事件可改变角色立场与关系，但不改写最具辨识度的底层性格底色。
3. **呈现而非评价（Show, Don't Judge）**：使用客观视听动作与原始台词直接呈现，省去认知过滤词（如“他看到/他意识到”）及对白音色与动机定性标签。
4. **因果顺叙与连动推进**：按客观发生顺序先因后果（例：`三天没进食，眼前一黑栽倒`）；连续动作一口气用具体动词推进。
5. **具象画面收尾**：章末与幕末严格停在具体人物动作、一句对白或环境声光变化上，把余味定性权留给读者。
6. **去对白表演欲与生活化表达**：角色在过日子而非开学术研讨会；涉及专业设定或战术时用日常交谈口吻自然带出。

## 2. 反 AI 味四代防御谱系与静态门禁词典 (`Static Prose Gate`)

四代手段由内向外叠加生效：**第 4 代（认知与动机边界） -> 第 3 代（前置句法纪律） -> 第 2 代（0 Token 代码配额扫描，带行号打回局部修补） -> 第 1 代（标签剥离检出，严禁静默删句破坏语法）**。

### 2.1 S 姐行文七刀（核心句法手术规范）

| 手术维度 | 典型 AI 病灶（扫描检出对象） | 正向目标写法 |
| :--- | :--- | :--- |
| **刀一：去对白标签与音色评判** | `声音不大却透着寒意`、`语气里带着三分无奈七分宠溺`、`话音刚落`、`尾音微颤` | 纯对白独立成行，或以具体肢体动作衔接对白（`她把茶杯顿在桌上：「出去。」`） |
| **刀二：封杀人体微距套话** | `指节泛白`、`喉结上下滚动`、`瞳孔微缩/地震`、`睫毛轻颤`、`指甲陷进掌心`、`眼眶泛起水汽`、`青筋暴起` | 退回中景写整体自然动作（`攥紧拳头`、`移开视线`、`把半截烟按灭`） |
| **刀三：封杀先否决对比句与未发生动作** | `不是 A，而是 B`、`并非…却是…`、`没有生气，只是有点失望`、`他没有抬头`、`她并没有立刻回答` | 直接陈述实际发生的正向状态（`他低着头`、`她沉默了两秒`），全肯定叙事 |
| **刀四：去抽象情绪定性** | `带着+抽象名词`（`带着笑意/带着审视`）、`天真得近乎残忍`、`气氛顿时缓和下来`、`这意味着` | 只给客观视听切片，由读者自行体会氛围 |
| **刀五：去翻译腔与伪学术腔** | `如此…以至于…`、`当…的时候`、`名为/关于/取而代之的是`、`变得+抽象词`、高频 `XX性/XX化` | 短句利落，主动语态优先，保留汉语自然的“了/着/过”节奏 |
| **刀六：陈腐比喻黑名单** | `像被按下了暂停键`、`像溺水者抓住救命稻草`、`像触电般缩回手`、`像精密运转的机器/程序` | 无精妙新奇比喻时一律用直白物理白描替代廉价明喻 |
| **刀七：去数字“三”凑数癖** | `退后三步`、`沉默三秒`、`吐出三个字` 等高频定式 | 改用自然约数或具体器物参照 |

### 2.2 零模型开销代码扫描规则表（按作品可开关与调参）

`Static Prose Gate` 在单章 `feat` 提交前执行正则与词表统计，每条规则均可独立开关与配置阈值，超限即输出精确行号触发局部 `Patch` 修补：

| 规则标识 | 匹配模式 / 词集示例 | 默认参考配额（按 3,000 字等比缩放） |
| :--- | :--- | :--- |
| `tag_residue` | `<blocking>...</blocking>`、`[SYSTEM]`、`<!-- ... -->` | 头部 `<blocking>` 校验提取后正文内 **`0` 残留** |
| `negation_contrast` | `(不是\|并非\|不像).{1,18}(而是\|却是\|更像)` | **`<= 1` 处** |
| `micro_anatomy` | `指节泛白\|喉结滚动\|瞳孔微缩\|睫毛轻颤\|表皮\|角质\|毛细血管\|心率\|肾上腺素` | **`0` 处** |
| `skeletal_quota` | `肩胛骨\|锁骨\|脊椎\|指骨\|腕骨\|肋骨` | 合计 **`<= 1` 处** |
| `deictic_density` | `那(张\|双\|个\|抹\|丝)`；`一(丝\|抹\|股\|阵)`；`X了X`（如 `看了看/顿了顿`） | `那+量词 <= 2`；`一丝/一抹 = 0`；`X了X <= 2` |
| `filler_cliche` | `极其\|不由得\|下意识地\|某种难以言喻\|不置可否\|取而代之的是` | 合计 **`<= 1` 处** |
| `ending_moralizing` | 末两段含 `他终于明白\|这一刻\|命运的齿轮\|等着(你\|他\|她)的回答` | **`0` 处** |
| `cross_chapter_simile` | 近 `N` 章（默认 `5` 章）内提取明喻短语（`像/如同/仿佛/好似 + 具象喻体`） | 同一具象喻体跨章重复 **`< 2` 次**（与声纹标本池彻底解耦） |

## 3. 环境补集机制与外置文风插件切分（已确认）

遵循**“强模型免绑死板填表拐杖，代码只补单章净室屏幕外的物理盲区”**原则，候选叙事机制切分为两层：

### 3.1 默认内聚的无感环境补集（对写手零填表负担）

1. **自由标签声纹标本池与 `LRU` 防连挂抽样**：
   - 静态前缀仅锁死零具象喻体的抽象句法纪律；动态标本池 `voice_samples.yaml` 支持按具体作品自由定义 `0~N` 个任意标签与短标本，装配器抽样时内聚 `LRU` 排序避开刚挂载过的标本，根治试播集单点比喻过拟合。
2. **导演自决戏剧聚焦（`focus_cast` / `background_cast`）与动作穿插对话**：
   - 不设任何固定焦点人数魔数上限（双人对峙或五人鸿门宴均由 `Planner` 按当场戏剧结构自由切分）：`focus_cast` 挂完整可见档案并以动作打断推进交叉对话，`background_cast` 压缩为单行环境态避免轮流点名汇报。
3. **存储层路人准入与前台镜头触发（`Spotlight Trigger`）**：
   - 单章临时路人放任自然命名，仅在存储层保持“未跨章复现且未绑伏笔前不建独立档案”不变量；离场重要角色在 `Dreaming` 阶段蓄力触及大事件临界点时，抛出 `Spotlight Trigger` 交后续前台章节正式叙事。

### 3.2 按书选装的可选认知插件（`craft_plugins`，默认关闭）

以下机制属于重型认知脚手架，默认为空数组 `[]` 不加载，仅在特定高心理博弈或强结构化作品中通过 `world/book_config.yaml` 显式挂载至 `Planner` 动态尾部：

- **`vad-bdi`（三维情绪钳位与认知演算链）**：按效价（Valence）、唤醒度（Arousal）、支配度（Dominance）限制情绪越界，并按 `信念 -> 欲望 -> 现实约束 -> 意图 -> 行动` 推演慢热关系。
- **`dual-reaction`（戏眼双反应择优）**：规划核心戏眼时先显式排除最俗套的第一顺位反应，采用贴合角色执念的克制第二反应。
- **`scene-act`（五元组场面调度 IR）**：细纲采用 `now（入场态势） -> beat（核心交锋） -> then（物理后果） -> initiative（主动权归属） -> interplay（视线/器物交互）` 结构化微节拍。

## 4. 明确排除的单轮聊天 RP 历史包袱

以下酒馆（SillyTavern）预设常见技巧属单会话聊天接口妥协，本引擎一律不用：

- 多轮伪造对话破限、`assistant_prefill` 抢占开头与越狱话术；
- 正文内嵌 `<!-- 草稿 -->` 注释或文末附挂 `<tucao>` 闲聊再靠前端隐藏；
- 输出后用客户端正则静默删句（易致语法残缺，统一改为检出行号走局部 `Patch`）；
- 含随机数的动态宏（`{{random}}` / `{{roll}}`，破坏静态前缀一致性）；
- 耦合特定聊天前端的气泡/CSS 标签与“等待用户接话”选项列表。
