02
Four Axioms

四条底层公理

经过多轮架构证伪和奥卡姆剃刀精简后保留下来的四条约束。后面每个模块都能追溯到其中一条，每条也都对应一项被砍掉的复杂度。

壹
Axiom 01 · 单模同构

Bootloader 吃脏活，运行时零分支

"原创与同人，只在开机第 0 步有区别。"

引擎内核里不拆分"原创模式"和"同人模式"。无论是从一句话点子生成的大纲，还是从外部导入的几十万字同人世界书，都在开书第 0 步编译成同一套标准文件，运行时内核统一调度。

剃掉双模式内核、运行时的模式分支判断
贰
Axiom 02 · 缓存与锐度解耦

检索畅读 300K，执笔守住 25K

"缓存便宜，不代表注意力也便宜。"

借助 Claude 提示词缓存的 ttl: "1h"（首次写入 2× 基准价，命中读取低至 0.05× 并自动续期），检索和离线整理工种可以畅读 200K–300K 索引。执笔写手即使缓存免费，总窗口也锁在 15K–25K，规避长窗口下的 Context Rot。

剃掉"缓存免费就全塞给写手"的冲动
叁
Axiom 03 · 不可变原典

已归档即只读，穿帮向前圆

"像职业连载作家一样打补丁，而不是重写历史。"

已归档章节就是只读区块。细微穿帮采用 向前打补丁（Forward Retcon）在后文自然圆回；重大方向调整直接用原生 Git 回滚到指定章节，截断重跑。

剃掉原地回改几十章前的定稿并级联重算全书
肆
Axiom 04 · 流程外运维

零审批卡点，人只看遥测

"人是全自动生产链中的延迟瓶颈。"

主循环内没有任何人工审批卡点。审美不下放给弱模型，字面核查不越权评判文笔。人类作为流程外 SRE 只看零成本遥测趋势，通过异步信号队列在章节安全间隙微调方向。

剃掉主循环里的人工审批、熔断后停机等人
03
Step 0 · Bootloader

开机第 0 步：创世与同人导入

为了避免"垃圾进、锁死百万字垃圾出"，全书开机先过统一引导器。这也是整条流程里唯一鼓励人类花 3–5 分钟做选择题的高杠杆环节。两条入口路径最终编译出完全相同的文件集。

i

自爆俗套，戏核三选一

输入一句话种子：废部边缘的旧校舍同好会。引导器先列出该题材最平庸的默认走向直接拉黑，再生成 3 组互斥的人物执念与核心错位关系供选择。不允许模型顺着一句话直接推 50 章大纲，否则必然滑向训练语料的最大公约数。

ii

先写试播集，再逆向抠取黄金声纹

不写"文笔细腻克制"这类抽象形容词。如果用户提供 500 字名家段落，只做脱敏句法解构（句均长度、冷暖比喻倾向、留白密度）；没有范文时，针对第 1 章同一冲突微场景，用 3 种具象笔法各写 350 字盲测小样：

i 选定后打磨完整的第 1 章试播集（3,000 字），原封不动摘出最出彩的 4 段旁白与对话，锁入 world/static_base_and_voice.md，再据此逆向生成首批核心人物卡。
iii

从卷末终局倒推拐点

第一卷大纲先锚定第 50 章的终局底牌，再倒推出 Ch.38、Ch.24、Ch.12 三个中继翻转节点，写入 future_horizon.md，并附带阶段锁。逐章细纲只展开前 5 章（延迟绑定）。

细纲 Ch.01–05
● 终局底牌： 阶段锁：Ch.24 前严禁提前掀底牌

迷雾地图，按卷扩建

开局静态世界底座控制在 3,000 字以内，只包含第一卷的舞台边界。第 50 章收官换地图时，再触发卷间引导扩建第二卷底座，并更新一次 1 小时缓存前缀。

Repository & Git

            
一个 Git 仓库装下整本书

            
全书的状态、设定、大纲、索引与定稿，全部以 UTF-8 行级纯文本（Markdown / YAML / JSONL）存在单一 Git 仓库里。1,000 万字正文只有约 30MB，没有任何二进制向量库黑盒，天然适合 Git 增量压缩和 git diff 审计。

05

          

            
Storage · Cache · Contracts

            
存储模型、前缀缓存与时序数据契约

            
千万字小说的记忆问题，可以拆成四个工程问题：怎么拼 Prompt 才能不掉缓存，怎么在 3,300 章里精确找回一句话，怎么记住"曾经拥有、后来失去"，以及怎么对抗大模型自带的原著记忆。

          

        


        
        

          
5.1永不掉缓存的 Prompt 物理拼装顺序

          
Claude 按 tools → system → messages 的顺序做前缀累积哈希，断点前任何一个字节变动都会让后续缓存失效。所以内核严格前静后动：断点之前整卷 50 章一个标点都不改。把鼠标移到各段上查看说明。

08

          

            
Self-Healing & SRE

            
无人化自愈闭环与晨间 30 秒看板

            
一夜挂机生成二十万字新稿，人类不用逐章通读。内核自己处理三类故障；人只看 4 项零成本遥测，必要时往信号队列里留一句话。

          

        


        

          

            
章内死锁自动重规划

            
细纲本身有物理悖论（比如要求左臂伤残的主角双手引体翻墙），连续 2 轮过不了核查时，内核不熔断停机等人：直接销毁草稿，把异常抛回 Planner 改写破局方式，最多允许重排 1 次。

            
Checker ✗✗→销毁草稿→Planner v2→Writer

          

          

            
台词谎言与客观事实分流

            
角色在对话里撒谎或嘴硬时，更新器和核查兵对照上下文缓冲，识别出主观宣称，禁止它污染物理库存，自动转记到听话者的主观认知偏差（Epistemic Bias）。

            
台词宣称→≠ 客观库存→听者认知偏差

          

          

            
跨章微瑕向前圆谎

            
每 5 章的 Dreamer 发现已归档章节有轻微漏检（比如没交代主角为何认得地下室的路），不回改历史定稿，而是给下一章 Planner 派发高优先级 Retcon Patch 工单，在后文顺手补一句。

            
Dreamer 发现→Retcon 工单→下一章圆回

用 40 章（约 12 万字）同源种子全自动盲测，量化本架构相对传统"滚动续写 + 单文件覆写变量表 + 向量 RAG"基线的工程优势。前 5 章预埋 10 枚长程探针，最后 5 章定向诱发。
